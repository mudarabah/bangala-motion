# Prompt: create a new style from a reference (paste into the agent)

```
Use the motion-style-kit skill, Job 2.

Reference: <path to video or folder of screenshots>
New style name: <short-kebab-name>

1. Extract frames with scripts/extract-frames.sh and study all of them.
2. Sample real colors from key frames with a small script.
3. Fill styles/<name>.md from styles/_TEMPLATE.md and write templates/theme.<name>.ts.
4. Build a 10-second "StyleTest" composition (headline with keyword, one card, icon cluster, one transition) and show it in Studio.
Do not copy any logos, names, characters or exact layouts from the reference: only the visual language.
```
